# SHOGIMAN-EXPO

App Store submission build of **SHOGI FRONTLINE**, implemented with Expo / React Native and built with EAS.

## Baseline

- Expo SDK 57
- React Native 0.86
- Portrait-only iPhone layout
- MILITARY / SHOGI display modes
- EASY / NORMAL / HARD CPU selector
- 9x9 touch board with legal-move highlights
- CPU pieces rotated 180 degrees
- Bottom tools: AI / GUIDE / SET
- EAS preview / production build profiles

## Local start

```bash
npm install
npx expo start
```

## EAS initialization

After signing in to Expo, run:

```bash
npx eas-cli@latest init
```

Then replace the temporary `extra.eas.projectId` value in `app.json` with the project ID generated by EAS.

For a cloud iOS build:

```bash
npx eas-cli@latest build --platform ios --profile preview
```

No local Mac is required for the EAS cloud build itself.
